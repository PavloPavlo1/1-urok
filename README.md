# Шахи

Україномовна шахова гра для браузера. Грати можна за посиланням:
https://pavlopavlo1.github.io/1-urok/

## Режими

- **Соло** — гра проти комп’ютера з трьома рівнями складності. Дошка перевертається після кожного ходу.
- **Дуо** — гра удвох на одному пристрої. Дошка не перевертається.
- Білі ходять першими. Координати дошки залишаються на місці.

## Можливості

- Повні правила: рокіровка, взяття на проході, перетворення пішака, шах, мат і пат.
- Нічия за правилом 50 ходів, триразовим повторенням або браком матеріалу.
- Ходи натисканням або перетягуванням, підсвічування легальних ходів, підказка.
- Скасування ходу, запис партії та показ взятих фігур.
- Партія зберігається в браузері.
